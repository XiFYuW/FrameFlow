# Agents

This repository is a model-facing video pipeline. Before doing any work here, read `skills/frameflow/SKILL.md` and follow its workflow.

All content (script, canvas, timing, artwork, fonts, audio, wording) lives in an external content pack. Never edit `src/`, `scripts/` or `remotion.config.ts` to produce a video, and never add media files to this repository.

Human documentation: `README.md` (English, canonical) and `README.zh-CN.md` (Simplified Chinese). Both are documentation only and are not inputs to the pipeline.
